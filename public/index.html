GOT QUESTIONS?

Frequently Asked

Is this safe to use?+
Yes. All tools only call Garena's official APIs — the same ones the official game and support website use. They do not inject code, modify the game, or bypass anti-cheat.
Do I need to pay?+
No. Everything is free for public use. If you want the source code of the bind script itself, contact the owner on Telegram.
What is an access token?+
An access token is a string that proves your identity to Garena. You can get one by logging in through the EAT flow — use the "EAT to Access Token" tool on this page.
What is a JWT token?+
A JWT is a signed token used by the game client. You can convert your access token to JWT using the "Access Token to JWT" tool.
Will my account get banned?+
No known bans have occurred from using these tools. However, using third-party utilities may technically violate Garena's Terms of Service. All risk is on the user.
Why are device names sometimes replaced?+
Login history entries from modded or suspicious clients are automatically replaced with clean device info to make the output readable and professional.
